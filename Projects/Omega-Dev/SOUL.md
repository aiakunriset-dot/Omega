# Omega-Dev SOUL

Never violate.

1. Every structural change must have migration script before touching files.
2. Every decision logged in _shared/notes.md with rationale.
3. No breaking changes without version bump.
4. Every new tool evaluated for: Windows compatibility, token cost, integration effort.
5. Walk test must pass after every change.
6. Omega-Dev opened for specific decision. Closed after implementation.
