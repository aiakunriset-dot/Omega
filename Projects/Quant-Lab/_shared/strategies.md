# Strategies Catalog

Semua strategi yang pernah dipertimbangkan, sedang diuji, atau diarsipkan.
AI membaca file ini untuk tahu strategi mana yang aktif sebelum mulai Stage 1.

## Status legend

| Status | Artinya |
|--------|---------|
| `idea` | Tercatat, belum diriset |
| `in-research` | Stage 01 aktif |
| `in-development` | Stage 02 aktif |
| `in-audit` | Stage 03 aktif |
| `passed` | Audit lulus, dikemas di Stage 04 |
| `failed` | Audit gagal, diarsipkan dengan alasan |
| `archived` | Tidak aktif lagi |

## Format entry

```markdown
### Strategy: [nama]
- **Status:** [legend value]
- **Hypothesis:** satu kalimat — edge apa yang dieksploitasi
- **Market:** [aset/market target]
- **Timeframe:** [1h / 1d / dll]
- **Added:** YYYY-MM-DD
- **Last updated:** YYYY-MM-DD
- **Notes:** apapun yang relevan
```
