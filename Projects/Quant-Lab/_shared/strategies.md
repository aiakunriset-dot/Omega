# Strategies Catalog

All strategies ever considered, tested, or archived.
AI reads this file to identify the active strategy before starting Stage 1.

## Status legend

| Status | Meaning |
|--------|---------|
| `idea` | Recorded, not researched |
| `in-research` | Stage 01 active |
| `in-development` | Stage 02 active |
| `in-audit` | Stage 03 active |
| `passed` | Audit passed, packaged in Stage 04 |
| `failed` | Audit failed, archived with reason |
| `archived` | No longer active |

## Format entry

```markdown
### Strategy: [nama]
- **Status:** [legend value]
- **Hypothesis:** one sentence — what edge is exploited
- **Market:** [aset/market target]
- **Timeframe:** [1h / 1d / dll]
- **Added:** YYYY-MM-DD
- **Last updated:** YYYY-MM-DD
- **Notes:** anything relevant
```
