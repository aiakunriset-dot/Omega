# Backups

Backup hooks. Kosong di V1.0.

## Purpose

Tempat untuk skrip backup otomatis dan snapshot penting.
Git adalah backup utama. Folder ini untuk backup tambahan jika diperlukan.

## Recommended Backup Strategy

1. **Git (primary):** `git commit` setelah setiap session
2. **External drive (secondary):** Copy `C:\Omega\` ke drive eksternal berkala
3. **Cloud (optional):** Sync ke Google Drive / OneDrive jika diperlukan
