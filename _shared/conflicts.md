# Conflicts — Cross-Project Contradictions

Contradictions across projects that need to be resolved.

## Format

```markdown
### Conflict: [description]
- **Project A:** [project] states [X]
- **Project B:** [project] states [Y]
- **Impact:** what is affected
- **Status:** `unresolved` | `resolved: [decision]`
- **Date found:** YYYY-MM-DD
```

## Rules

- If two projects have conflicting conventions, record them here
- Human resolves all conflicts — AI must not decide independently
- After resolution, update the status; do not delete the entry
