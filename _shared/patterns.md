# Patterns — Proven Across Projects

Pola yang terbukti efektif dari penggunaan nyata. Tumbuh seiring waktu.

## Format

```markdown
### Pattern: [nama pola]
- **Context:** kapan pola ini berlaku
- **Pattern:** deskripsi pola
- **Why it works:** alasan efektif
- **First seen:** YYYY-MM-DD di [proyek/stage]
- **Verified in:** [daftar proyek yang konfirmasi]
```

## Aturan

- Masuk ke sini hanya jika terbukti di lebih dari satu konteks
- Satu kali penggunaan → catat di error log dulu, promosi ke sini setelah terbukti
- Human approves setiap entry baru
